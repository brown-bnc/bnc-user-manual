# Anonymization and Defacing on XNAT

We support two complementary tools to enable the removal of potential Protected Health Information (PHI) or Personally Identifiable Information (PII) from MR data stored on XNAT. We can configure your XNAT projects to automatically:

1. [remove potential PHI/PII from DICOM metadata as the DICOMs arrive from the scanner](project-level-de-identification.md)
2. [remove potentially identifiable facial features from anatomical scans](removing-identifiable-facial-features.md)
